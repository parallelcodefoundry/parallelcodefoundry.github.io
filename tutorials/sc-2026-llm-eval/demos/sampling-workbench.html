Dataset and method

MonkeyBusiness provides 10,000 responses per question. This demo bundles the first 100 for each of its 127 GSM8K questions for a download of about 7 MB. The 100-response pool is a demo size limit, not a dataset limit. No questions or responses were chosen by correctness. The tutorial uses 84 test questions and 43 reserved questions, all drawn from the upstream test set.

Each repetition draws without replacement. The baseline and your method share the first response. Voting groups numeric answers extracted after ####; invalid answers receive no vote. If none can be extracted, the method returns no answer and receives no success. Final scoring uses the released correctness labels.

Results describe this recorded subset, not the full benchmark. Repetitions reuse the stored outputs; they are not new model generations or confidence intervals. Measured tokens and elapsed time are unavailable; cost uses a labeled text-length estimate. Reserved questions are bundled locally; keeping them separate is a workshop convention.

Source: Monkey Business, released with Brown et al., Large Language Monkeys (2024). See provenance, licenses, and reproduction.
