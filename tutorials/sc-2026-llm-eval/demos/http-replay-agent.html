Demo 2

Replaying Logged Generations

This demo runs a tiny agent through an OpenAI-compatible API, records the HTTP response, and then replays the same response later. The point is to separate the workflow you are evaluating from the model call you happened to receive during one run.

Agent

The agent checks a short task description for reproducibility details, asks a model to write a brief trace note, and saves the run so it can be inspected later.

  • .agent_traces/last_run.json
  • .openai_http_cache/*.json

The local model runs behind a llama.cpp OpenAI-compatible server, so the same recorder works for local and hosted model calls. The scripts are in the public tutorial repository .

What To Check

Check that the model output is the same when you run with --replay. Then open the trace and cache files to see what was saved.

The cache should include the request and response, but not Authorization or api-key headers.

The small local model is only there to make the demo practical on a laptop. Agent outputs will look more realistic with commercial models.

Run It Locally

  1. Get the code

    Clone the public tutorial repository.

    git clone https://github.com/parallelcodefoundry/llm-eval-isc-2026.git
cd llm-eval-isc-2026

  2. Install the requirements

    Run this from the repository root.

    python -m venv .venv
source .venv/bin/activate
python -m pip install -r demos/http_replay_agent/requirements.txt

    On Windows PowerShell, activate with .venv\Scripts\Activate.ps1.

  3. Start the local model server

    Leave this terminal running. The first run downloads the default GGUF model and starts the server on port 8008. 

    python demos/http_replay_agent/start_local_server.py

  4. Run the agent

    Use a second terminal with the same virtual environment.

    python demos/http_replay_agent/agent.py

  5. Replay the same call

    This should reuse the cached HTTP response for the matching request. 

    python demos/http_replay_agent/agent.py --replay

Common Checks

If the server is running correctly, the agent should print a tool result, a raw model note, the trace path, and the cache directory. 

python demos/http_replay_agent/agent.py \
  --local-base-url http://127.0.0.1:8010/v1

Use the alternate base URL only if you started the server on a different port, such as --port 8010.

Hosted OpenAI Variant

The hosted path uses the same agent and recorder, but sends the request to the OpenAI API. 

export OPENAI_API_KEY=...
python demos/http_replay_agent/agent.py --backend openai
python demos/http_replay_agent/agent.py --backend openai --replay
