Evaluating LLM repair

A model writes code, tests find a failure, and the model tries again. Does LLM repair help?

Outputs from Self-Repair on HumanEval coding tasks. Based on Olausson et al. (ICLR 2024).

The Task

Generate a program that passes the tests. If it fails, ask the model to explain the error and repair its code.

      Dataset and method
      
Recorded programs and repairs from the Self-Repair dataset (Olausson et al., ICLR 2024). This demo uses all 164 HumanEval tasks, with 20 initial programs and up to five repairs per failed program. Runs reuse these outputs and stop at the first recorded test pass; there is no separate hidden-test score. Section 2 compares fresh generation with a repair reference at matching settings.
